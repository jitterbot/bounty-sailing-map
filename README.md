# Welcome to the Bounty Sailing Map plugin README!

# 

Bounty Sailing Map is a RuneLite plugin for OSRS that displays Sailing bounty creature locations directly on the world map.

===



# \~ Features

# 

\- Automatically displays map markers for your active Sailing bounty creatures.

===

\- Remembers your active bounty tasks between RuneLite sessions.

===

\- Includes known spawn locations for all Sailing bounty creatures.

===

\- Provides a "Show all creatures" option to display every bounty creature location at once on the world map.

===

\- Allows the marker colour for each creature to be customised individually.


===

# \~ How to use the plugin

# 

# 1\. Enable "Bounty Sailing Map" in RuneLite.

# 2\. Right-click your Captain's Log in your inventory.

# 3\. Select the "View-tasks" option.

# 4\. Open the world map.

# 

# The plugin will detect your active bounty creatures and display their known locations on the world map.

# 

# Your active bounty list is saved, so you don't even need to open "View-tasks" every time RuneLite starts.

# 

# When your bounty tasks change, open the "View-tasks" panel again in your Captain's log to update the map again.

# 



# \~ Show all creatures

# 

# Sliding "Show all creatures" on in the plugin settings will display the locations of every bounty creature regardless of your current tasks. You can turn it off by sliding it back again.

# 

# Turning this option off returns the map to displaying only your active bounty creatures.

# 



# \~ Coded creature colours

# 

# Each bounty creature has its own colour picker tool.

# 

# Open the Bounty Sailing Map settings and expand the Marker section to customise their colours.

#

# \~ Notes

# 

Just a disclaimer, creature locations are displayed as world map markers. Some creatures have many different spawn locations, so enabling "Show all creatures" can result in a large number of markers cluttering the world map. 

If any additional creatures are added to the game, I will add them to the plugin.
